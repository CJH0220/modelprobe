# mprobe-dashboard — 结果查看

工具位于本仓库根目录。**本 skill 的全部操作均为只读**，
不发起网络请求、不产生费用。

## 路由判定：图形界面还是命令行

| 用户诉求 | 处理 |
|---|---|
| 趋势图、逐维分布、逐题矩阵 | 启动浏览器界面 |
| 「上次跑的结果」「多少分」 | 命令行即可。**不要为查一个数值启动服务** |

## 命令行查询

```bash
python -m mprobe status --json                    # 最近若干轮
python -m mprobe status --run <run_id> --json     # 指定轮次的进度与结果
python -m mprobe compare <run_a> <run_b> --json   # 对比两轮
python -m mprobe bank info --json                 # 题库现状
python -m mprobe tiers --json                     # 各档位的结论许可
```

完整报告位于 `data/runs/<run_id>/report.md`，可直接读给用户。

原始响应位于同目录 `raw.jsonl`。判分器变更后用该文件重放即可重算，
**无需重新采样**。该留档已三次用于恢复数据。

## 浏览器界面

```bash
python -m mprobe web
python -m mprobe web --port 9000 --no-open
```

默认地址 `http://127.0.0.1:8790`；端口被占用时自动顺延并在启动日志打印实际端口。
将 URL 交给用户，**不要在会话中描述图形内容**。

五个页签：总览、单轮、监控、端点、题库。

**界面为只读**：接口全部为 GET，POST 一律返回 405。
增删端点与发起测评走命令行或 MCP。**不得让用户以为可在网页内发起测评。**

> **禁止自行拼装 HTML 页面代替该界面。** 那将构成第二套展示逻辑，
> 与本项目「只有一份实现」的首要约束冲突。

四条界面硬规矩（用户问及时如实说明）：

| 规矩 | 说明 |
|---|---|
| 仅绑定 `127.0.0.1` | 不提供 `--host` 参数。远程访问用 `ssh -L 8790:127.0.0.1:8790` |
| 密钥永不回显明文 | 仅显示掩码与来源；webhook 仅显示域名与前两段路径（飞书/Slack 的 token 位于路径中） |
| 题数不足的维度不画分数 | m<6 不画、6–11 虚线、≥12 实线，每维附最小可检出量 |
| 不同 `bank_rev` 不连线 | 按 `模型 + 档位 + 题库版本 + 端点指纹` 四键分组，任一不同即另起图表 |

## 趋势解读的三条禁令

以下三项须主动向用户说明——图形在这三种情况下**外观完全正常**：

| 禁令 | 原因 |
|---|---|
| 不同 `bank_rev` 的点不可连线 | 题库变更后该线不再具有含义，而图形仍会绘制。属静默失效 |
| 不同端点配置的点不可连线 | `max_tokens` / `temperature` 任一变更即导致端点指纹变化，前后不可比 |
| 不可将本次分数与上周分数相减 | 既有实测：一次判分器修复使同一批存档响应的通过率由 79.5% 变为 89.5%。**该虚假变化的量级超过多数真实的模型间差异。** 趋势判读只能走三态判定，而三态判定内部与同一版基线比较 |

## 结果转述规范

`report.md` 的结论卡分三层：事实层、判读层、许可层。
**禁止只转述事实层的分数**——判读层的 ± 区间与许可层的禁止用法同等重要。

## 不予触发的表述

| 用户表述 | 原因 |
|---|---|
| 测一下 X | 需发起测评并产生费用，路由至 `mprobe-eval` |
| 有没有变笨 | 需判定，路由至 `mprobe-monitor` |
| 把图导出成 PPT | 本工具不提供导出功能 |
| 哪个模型比较好 | 属选型问题，本工具不产出排名 |
