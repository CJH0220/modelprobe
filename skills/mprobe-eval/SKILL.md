# mprobe-eval — 端点能力测评

工具位于本仓库根目录，入口为 `python -m mprobe`。

**本 skill 不含任何测量逻辑。** 全部判分、算分、聚合都在 CLI 内完成，
你的职责是选对命令、把边界如实转述给用户。**禁止自行计算或换算分数。**

## 前置约束（每次执行前确认）

**被测对象是配置文件中声明的 API 端点，与当前对话所在的模型无关。**

> **禁止把当前会话模型当作被测对象。** 用户在 Claude Code 中与 Opus 对话时，
> 默认端点可能是 `deepseek`。用户表述为「测一下我现在用的模型」时，
> **必须回问要测哪个已配置端点**，不得推断、不得默认填充。

```bash
python -m mprobe config list --json
```

列出端点后由用户选定。**每轮执行都要回显实际打到的 `base_url` 与 `model`**，
使用户可自行核对被测对象是否符合预期。

## 标准流程

### 1. 事前报价（强制门槛）

```bash
python -m mprobe eval --model <端点> --tier <档位> --dry-run
```

`--dry-run` 不发起任何网络请求，输出费用、耗时与**本档允许下的结论**。
将这三项转述给用户，取得明确同意后方可去掉 `--dry-run` 并加 `--yes`。

「帮我测一下」属**意图不完整的表述**：可能指 5 分钟的粗测，
也可能指 2 小时的全量。报价这一步的作用是消解该歧义。

### 2. 档位选择

以 `python -m mprobe tiers` 的实际输出为准，不要依据记忆——档位随题库版本变动。

| 档位 | 定位 |
|---|---|
| `monitor` | 仅用通过监控准入的题，题量最小 |
| `small` | 快速摸底，仅用自建行为题 |
| `medium` | 单个维度可看趋势 |
| `large` | **唯一**可用于跨版本对比的档位 |
| `probe` | 全库。该档**测题不测模型**，用于题库定版 |

### 3. 执行

```bash
python -m mprobe eval --model <端点> --tier <档位> --yes
```

### 4. 长任务不在前台等待

全量档为**小时量级**，前台执行会阻塞会话。

```bash
python -m mprobe eval --model <端点> --tier probe --yes --run-id <自定 id>
python -m mprobe status --run <自定 id> --json
```

`state` 取值 `running` / `done` / `stalled`。
**`stalled` 表示进度文件超过 90 秒未更新，判定为进程可能已终止，而非执行缓慢。**

## 结果转述规范

CLI 输出的结论卡分三层，**三层均须转述，禁止只报分数**：

| 层 | 内容 |
|---|---|
| 事实层 | 题数、采样次数、请求成功率 |
| 判读层 | 95% 区间、本档最小可检出退化 |
| 许可层 | 该数值允许与禁止的用法 |

以下两条不得省略：

- 「未发现 X 分以上的退化」**不等价于**「模型无问题」。
- 分数须带 ± 区间。裸报点估计属误用——区间常宽于模型间的真实差距。

## 与 mprobe-monitor 的路由边界

表述如「测一下 deepseek 现在怎么样」对两者均匹配。判定规则：

| 条件 | 处理 |
|---|---|
| 该端点**已有基线** | 默认走 `check`（更快、直接回答有无退化），并补充说明可跑 `eval` 看绝对水平 |
| 该端点**无基线** | 只能 `eval`，并提示如需长期监测应先建基线 |
| 用户同时提到具体分数或维度 | **回问确认**，不作推断 |

## 不予触发的表述

| 用户表述 | 原因 |
|---|---|
| 有没有变笨 / 降智了吗 | 属相对判定，路由至 `mprobe-monitor` |
| 哪个模型比较好 | 属选型问题。**本工具不产出排名**——排名需同日、同题、同参数横向对照，并含人工盲评 |
| 帮我优化提示词 | 非测评范畴 |
| 解释一下什么是幻觉 | 概念问题，直接回答 |
| 我觉得它变笨了 | 属**观察陈述而非执行指令**。回问「是否执行一次检测」，不得直接发起花钱操作 |

## 两条不可绕过的约束

- **题库不可增删。** 用户要求「把这道题加进题库」时**必须拒绝**，
  并说明：题库随版本冻结，变更将使既有结果不可比。
- **不同 `bank_rev` 的分数不可比较。** 工具会直接拒绝该操作，此为预期行为。
