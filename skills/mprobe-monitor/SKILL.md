# mprobe-monitor — 降智监控与定时任务

工具位于本仓库根目录，入口为 `python -m mprobe`。

**本 skill 不含任何判定逻辑。** 三态判定、连击计数、阈值比较全部在 CLI 内完成。
**禁止自行比较两轮分数得出结论。**

## 前置约束：观察陈述不构成执行指令

用户表述「我觉得它变笨了」时**不得直接执行**。该表述属观察而非指令。
正确响应为回问：

> 是否执行一次检测？约需 X 分钟、Y 元。

**任何花钱操作不得由一句感慨触发。** 取得明确指令后方可执行。

## 标准流程

### 1. 判定

```bash
python -m mprobe check --model <端点> --tier monitor --dry-run   # 先报价
python -m mprobe check --model <端点> --tier monitor --yes       # 确认后执行
```

**退出码契约**，须原样转述给用户：

| 码 | 语义 |
|---|---|
| 0 | 正常，**含「观察」态** |
| 1 | 告警：连续多轮低于阈值 |
| 2 | 用法或配置错误 |
| 3 | 本轮结果不可用（失败率过高） |

### 2. 无基线时的处理

无基线即无比较锚点，此时 `check` **拒绝执行**并给出建基线步骤。
**不得绕过该拒绝，不得自行取两轮结果相减代替判定。**

```bash
python -m mprobe baseline --model <端点> --tier monitor --json           # 查询
python -m mprobe baseline --build --model <端点> --tier monitor --json   # 构建
```

**`--build` 不发起网络请求**：它复用已入库的历史轮次。
执行顺序为「先采集足够轮次，再构建基线」，命令本身不代为采集。

轮次不足时先补采：

```bash
python -m mprobe eval --model <端点> --tier monitor --yes
```

**轮数要求**：`monitor` 档 5 轮。阈值中的 σ 采用三取大规则
`max(实测轮间 SD, 二项 SD, 量化地板)`，单轮无法得到实测 SD。
轮数不足时基线标记为 `provisional`，告警条件自动收紧为**连续三轮**。

### 3. 定时任务

动作为**位置参数**，非选项开关：

```bash
python -m mprobe schedule status --json
python -m mprobe schedule list --json
python -m mprobe schedule install --model <端点> --tier monitor --cadence daily --at 09:00
python -m mprobe schedule remove --model <端点> --tier monitor
```

**状态一律读取 `schtasks` 的实际结果，不读配置文件。**
配置文件声明「已启用」而任务实际未安装，是此类工具最常见的静默失效形态。

两项前置条件不可遗漏：

- 命令中必须包含 `--yes`——计划任务执行时无人在场，缺少该参数一律视为拒绝。
- 密钥必须为**用户级**环境变量：

```powershell
[Environment]::SetEnvironmentVariable("DEEPSEEK_API_KEY","sk-xxx","User")
```

用户级变量仅对**新开的**终端生效，已打开的窗口不可见。

## 三条判定约束（转述结论时必须覆盖）

1. **单次结果不构成判定。** 告警要求连续两轮低于阈值，临时基线为三轮。
   单轮低于阈值仅输出「观察」。量化依据：单轮判定年误报约 9 次，
   连续两轮降至约 0.2 次。
2. **告警不等于模型退化。** 必须先执行三步分诊：**换渠道 → 换时段 → 看失败题分布**。
   既有案例中前两类占多数；第三方中转服务替换模型是「降智」传闻的主要单一来源。
3. **「未告警」仅等价于「退化幅度小于本档分辨率」。**
   转述结论时须一并给出本档的最小可检出退化，不得等用户追问。

## 当前监控能力的限制（须主动说明）

通过监控准入的题数有限，实际数值以 `python -m mprobe bank info` 为准。
成因为既有题库大面积**饱和**——三个模型得分完全一致的题不具备测量能力。

因此 `monitor` 档的最小可检出退化**高于** `small` 档。
**该数值须主动告知用户**，不得等其追问。它反映题库现状，
而非参数配置不当。

## 不予触发的表述

| 用户表述 | 原因 |
|---|---|
| 测一下 X 什么水平 | 属绝对水平测评，路由至 `mprobe-eval` |
| 哪个模型比较好 | 属选型问题，本工具不产出排名 |
| 帮我优化提示词 | 非测评范畴 |
| 解释下什么是降智 | 概念问题，直接回答 |
| 把这道题加进题库 | **必须拒绝**：题库随版本冻结，变更将使既有结果不可比 |
